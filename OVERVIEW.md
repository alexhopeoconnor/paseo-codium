Open VSCodium Web inside Paseo or in a browser tab. Embedded mode shares one editor
per workspace, opens linked files without reloading it, and reports unsaved changes.
File tabs provide read-only previews.

Configure your authenticated Codium HTTPS address. Embedding requires the matching
companion extension on the same host and Unix account. See README.md for setup,
usage and Paseo's file-routing and tab-lifetime limitations.
